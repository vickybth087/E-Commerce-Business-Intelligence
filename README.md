# E-Commerce Business Intelligence Dashboard

## Project Overview
This project focuses on analyzing E-Commerce business performance using Power BI. The dashboard provides insights into sales, customers, products, revenue, and delivery performance using the Olist E-Commerce dataset.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Revenue: R$15.84 Million
- Total Orders: 98,666
- Total Customers: 96,096
- Average Order Value: $160.58
- Average Review Score: 4.09
- Average Delivery Time: 12.50 Days

## Dashboard Features
1. Monthly Revenue Trend
2. Sales by Product Category
3. Sales by Customer State
4. Order Delivery Performance
5. New vs Repeat Customers
6. Product Quantity Analysis
7. Interactive Filters for Category, State, Year and Order Status

## Key Business Insights
- Total revenue reached approximately R$15.84 million.
- The business recorded 98,666 orders.
- The dashboard helps compare sales performance across product categories and customer states.
- Average delivery time was 12.50 days.
- Average customer review score was 4.09.

## Business Recommendations
- Focus on high-performing product categories.
- Improve delivery performance.
- Monitor customer satisfaction.
- Develop strategies to encourage repeat purchases.
- Analyze state-wise sales to identify growth opportunities.

## Conclusion
This project helped me develop practical skills in Power BI, data visualization, business intelligence, and data-driven decision-making.
